# Inky Paws 🐾

*Where stories bloom softly.*

A cozy, local-first fanfiction writing studio.

The existing GitHub Pages address and application scope remain unchanged so chapters, characters, canon and settings stored in this browser remain accessible after the visual rebrand.

The icon is the approved black kitten reading a pink book, with little ink paw prints. The full-size image is embedded in `icons/user-cat-logo.svg`; generated PNG variants are used by the installed app.
